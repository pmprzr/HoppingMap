# HOPPINGMAP # 

Funproject for showing upcoming matches of Bundesliga 1, 2 and 3 for improving planing for groundhopping

Data Source: https://www.openligadb.de/

## Installation with Visual Studio ##

### Git ###
git clone https://github.com/pmprzr/HoppingMap.git

### NPM + Typescript ###

npm init -y

npm install leaflet

npm install --save-dev typescript

npm install --save-dev @types/leaflet

npx tsc --init

See also: https://learn.microsoft.com/en-us/visualstudio/javascript/tutorial-aspnet-with-typescript?view=visualstudio
